# Brief-logotyper

- `brief-horizontal.png`: originalloggan med vit text, för mörkt tema.
- `brief-light.png`: godkänd ljusbakgrundsvariant med mörkgrå text som tonar mot svart, turkost streck och originalets symbolfärger.
- `brief-vertical.png`: tidigare stående originalvariant.

Appen använder horisontell logga och samma slogan: Keep it brief, get it done.

Bockens inloggningseffekt är ett kodstyrt SVG-lager vid samma position som bocken i originalloggan. Resten av loggan är stilla. Effekten startar efter korrekt inloggning och respekterar minskad rörelse.
